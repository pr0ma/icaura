### 🔌 З якими інверторами працює ICAura?

Сучасні моделі JSDSolar та їх клони, які використовують протокол **Modbus** для спілкування з логером.

**Підтримувані моделі:**

* JSDSolar J12000HC-48 (12 kW, 48V)
* Anern FGI-S5000 (5 kW, 24V) — *перевірено на практиці*
* Anern FGI-S6500 (6.5 kW, 48V)
* ECG Solax ECG-HVM6.5KP-48V
* та інші сумісні пристрої.

**Перевірені в роботі на цей час:**

* Anern FGI-S5000 (5 kW, 24V)
  
💡 *Якщо нижня частина вашого інвертора виглядає схожим чином, скоріш за все, він сумісний з ICAura.*

### 🚀 Можливості

Локальний моніторинг та керування налаштуваннями інвертора **без хмарних підключень та китайських серверів**. Вся інформація залишається виключно у межах вашої локальної Wi-Fi мережі.

Ви отримуєте прямий доступ на читання та запис усіх регістрів інвертора, включно із захищеними правами адміністратора (наприклад, регістри калібрування вимірювальних модулів).

Повний список регістрів та їх призначення https://github.com/pr0ma/icaura/blob/main/INV-ModbusV1.20.xlsx

### 📌 Схема підключення

#### 1. Підключення до роз'єму інвертора
<img width="1096" height="976" alt="USB-A " src="https://github.com/user-attachments/assets/3e770c4f-9dff-42a5-bd1a-419316e5b05b" />

* **Pin 1 (+5V)** -> пін `VIN` (або `5V`) на платі ESP32 (живлення всієї схеми).
* **Pin 4 (GND)** -> спільний провід до `GND` ESP32 та `GND` (RS232) модуля MAX3232.
* **Pin 3 (RS232 TX)** -> вхід `RXD` (RS232) модуля MAX3232.
* **Pin 2 (RS232 RX)** -> вихід `TXD` (RS232) модуля MAX3232.

#### 2. Підключення модуля MAX3232 до ESP32 (з боку TTL)

* **VCC (MAX3232)** -> пін `3.3V` ESP32.
* **GND (MAX3232)** -> `GND` ESP32.
* **TXD (TTL) MAX3232** -> `TX2` (GPIO 17) ESP32.
* **RXD (TTL) MAX3232** -> `RX2` (GPIO 16) ESP32.

#### Зведена таблиця комутації:

| USB інвертор | Функція | Перетворювач MAX3232 | Плата ESP32 |
| --- | --- | --- | --- |
| **Pin 1** | +5V | — | `VIN` / `5V` (Живлення) |
| **Pin 2** | RS232 RX | TXD (RS232 side) | — |
| **Pin 3** | RS232 TX | RXD (RS232 side) | — |
| **Pin 4** | GND | GND (RS232 side) | `GND` |
| — | TTL TX/RX | TXD (TTL side) | `GPIO 17` (TX2) |
| — | TTL TX/RX | RXD (TTL side) | `GPIO 16` (RX2) |
| — | 3.3V Power | VCC (TTL side) | `3V3` |

### 📥 Прошивка ESP32

Можна використовувати будь-які зручні засоби для запису `.bin` файлів в ESP32. Для прикладу нижче наведено інструкцію для зручного прошишування через вебпереглядач за допомогою [esptool-js](https://espressif.github.io/esptool-js/).

#### 📋 Передумови та вимоги

1. **Браузер:** Потрібен браузер із підтримкою Web Serial API (Google Chrome, Microsoft Edge або Opera на ПК). *Safari та Firefox наразі цю функцію не підтримують.*
2. **Кабель:** Якісний USB-кабель із підтримкою передачі даних (Data Cable), а не лише для зарядки.
3. **Драйвери:** Якщо плата не визначається системою, встановіть драйвер USB-UART адаптера (найчастіше це **CP210x** або **CH340/CH341**).
4. **Файли прошивки:** Необхідні бінарні файли (`.bin`).

#### 🚀 Покрокова інструкція

* **Крок 1. Підключення плати**
1. Підключіть плату ESP32 до комп'ютера за допомогою USB-кабелю.
2. Відкрийте браузер (Chrome / Edge) і перейдіть за адресою: 👉 **[esptool-js](https://espressif.github.io/esptool-js/)**


* **Крок 2. Налаштування швидкості (Baudrate)**
У полі *Baudrate* виберіть швидкість передачі даних. Рекомендоване значення — **460800**. Якщо виникають помилки зв'язку, знизьте швидкість до **115200**.
* **Крок 3. Підключення до пристрою (Connect)**
1. Натисніть кнопку **Connect** у верхній частині сторінки.
2. У спливаючому вікні виберіть COM-порт, до якого підключено ESP32 (наприклад, `COM3`, `COM4` у Windows або `/dev/ttyUSB0` у Linux/macOS), та підтвердіть підключення.
*💡 Якщо плата не підключається автоматично:* Деякі плати ESP32 вимагають ручного переходу в режим завантаження. Для цього натисніть і утримуйте кнопку **BOOT** (або *IO0*) на платі під час встановлення з'єднання.


* **Крок 4. Додавання файлів прошивки (Flash Files)**
У секції *Flash Files* додайте необхідний `.bin` файл та вкажіть відповідну адресу пам'яті (*Flash Address*):
* **Для першої установки (чистий монтаж):** використовуйте файл, назва якого починається з **`SetupICAura`**. Адреса: **`0x0`**.
* **Для оновлень:** використовуйте файл, назва якого починається з **`UpdateICAura`**. Адреса: **`0x10000`**.



> ⚠️ **Важливо про очищення пам'яті (Erase Flash):**
> Перед завантаженням первинного файлу (`SetupICAura`) обов'язково очистьте Flash-пам'ять, натиснувши кнопку **Erase Flash**, і дочекайтеся завершення процедури. **Не робіть очищення** при завантаженні файлу оновлення (`UpdateICAura`).

* **Крок 5. Запуск прошивки та перезавантаження**
1. Натисніть кнопку **Program** (або *Flash*) і дочекайтеся завершення процесу.
2. Натисніть кнопку **Disconnect** у вебпереглядачі.
3. Натисніть кнопку **RESET** (або *EN*) на платі ESP32 (або просто перепідключіть USB-кабель), щоб пристрій перезавантажився та запустив нову прошивку.

### ⚙️ Перший запуск та налаштування ICAura

1. Переконайтеся, що все пройшло успішно: відкрийте налаштування Wi-Fi на смартфоні чи комп'ютері та знайдіть доступну бездротову мережу з назвою **`ICAura`**.
2. Підключіться до цієї мережі (пароль за замовчуванням: **`ic123456`**).
3. Після підключення у браузері має автоматично відкритися сторінка налаштувань. Якщо цього не сталось, вручну перейдіть за адресою: **`http://192.168.4.1`**.
4. Введіть назву вашої домашньої Wi-Fi мережі (SSID) та пароль від неї.
5. Придумайте та введіть власний пароль для доступу до вебсторінки ICAura.
6. За бажанням у розширених налаштуваннях можна прописати статичну IP-адресу (якщо цього не зробити, подивіться в роутері, яку адресу було призначено пристрою).

При першому вході введіть логін за замовчуванням: **`admin`** та створений вами на попередньому етапі пароль.

### 🔐 Рівні доступу

Інтерфейс ICAura максимально простий та інтуїтивно зрозумілий:

* **Level 0 (за замовчуванням):** базовий рівень доступу, що надає виключно статистичну інформацію.
* **Level 1:** доступ до налаштувань та патчів
* **Level 2:** повний доступ до читання та запису регістрів.

  **Доступи Level 1 та Level 2 надаються за запитом на електронну пошту icaura@proton.me з міркувань безпеки.**

  **Додавання функціоналу, правил, інтеграцій за запитом на електронну пошту icaura@proton.me.**
